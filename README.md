# Oh-My-DeepSeek-APP

<h1 align="center">Make DeepSeek Great Again!</h1>
<h3 align="center">让 DeepSeek 再次伟大！</h3>

<p align="center">在基础对话之上，持续增强 DeepSeek 的使用体验。</p>

## 有什么增强？

- **跨对话长记忆**：记住偏好和长期事实，新对话也能接着聊；从相关旧聊天中找回上下文，回答旁可查看来源。
- **记忆由你掌控**：添加、编辑、忘记、备份记忆，可关闭自动整理，也可让某段对话不参与记忆。
- **历史记录管理**：导入、导出聊天记录，导入过程有进度，完成或失败都有明确反馈。
- **Android 适配**：系统文件选择与保存、加密保存 API Key、返回键和麦克风权限适配。

保留基础对话、深度思考、智能搜索、文件与图片、语音输入和朗读。客户端不设每日聊天额度、4 万字输入上限或七天会话失效规则。

## 开始使用

1. 安装 APK（Android 8.0+），打开应用。
2. 在「设置 → 数据管理」填入自己的 **DeepSeek API Key**。
3. 开始聊天；试着说「记住，我喜欢简短的中文回答」。记忆可在「设置 → 记忆」管理。

直连 **DeepSeek 官方付费 API**，计费和服务端限制仍然适用；自动整理记忆会产生额外用量，可关闭。聊天与记忆保存在本机，使用时将所需内容发送给 DeepSeek。卸载前请导出备份。
