# 跨会话记忆

本版参考 ChatGPT 公开说明中的「保存的记忆」和「引用历史聊天」两类体验：[官方记忆说明](https://help.openai.com/en/articles/8590148-memory-in-chatgpt)。实现由本应用负责，不接入 ChatGPT，也不声称复现 OpenAI 的内部算法或召回效果。

0.4.0 新增 [记忆摘要](MEMORY_SUMMARY.md)：本机主题概览、可选的智能整理、直接编辑、划选/文字纠正预览、“不再提起”和删除并关闭记忆。

## 使用

- 输入框右侧的记忆图标，或「设置 → 记忆」，可查看开关、记忆列表和索引状态。
- 说「记住，我喜欢简短的中文回答」后，回复下方会显示整理状态。等「记忆已更新」后，新对话便可引用；未提取到新事实会显示「本轮未新增记忆」，也可手动添加。
- 可以修改或忘记单条记忆。独立的「忘记所有记忆」指令会在本机清空保存的条目，不额外调用提取接口；完整清空也可使用设置中的按钮。
- 「使用保存的记忆」关闭后，停止读取和自动新增，并同时关闭历史引用；条目仍保留。「自动整理新记忆」可以单独关闭，手动维护的条目仍可使用。
- 「本对话参与记忆」关闭后，当前对话不读取或新增记忆，也不作为其他对话的历史检索来源。新建对话前也可设定下一段对话是否参与。
- 回答旁的「记忆来源」列出本轮实际提供的条目和摘录，注明用户原话/助手回答，可跳转到原对话。提供了背景不代表模型必然采用其中每一项。

## 数据与费用

保存的记忆和全文索引位于应用私有 IndexedDB `ohmy-deepseek-memory`。原始聊天数据库 `chat-demo` 的版本和已有数据不迁移。原有聊天 ZIP 与记忆 JSON 分开备份；记忆 JSON 不含 API Key，导入时去重合并，不覆盖已有条目。

历史索引逐个读取本机对话，只索引当前选中的消息分支中的文字。附件原件、思考链、拒绝回答不进入索引；检测到常见密钥模式的文本也不进入。索引建立不调用模型，不批量上传旧对话。新问题在本机完成中文词/双字片段及英文词检索，最多发送少量相关摘录。关闭历史引用时清理索引，之后可重建。

自动整理处理符合条件的新用户消息。每轮额外调用一次 `deepseek-flash`，最多 1000 输出 token、25 秒超时，费用来自官方 API。提取失败时可以手动重试。请求使用 `safety_check: high`，返回内容经过 JSON 和字段校验。

## 从历史生成记忆

导入聊天 ZIP 成功后可选择「从历史生成记忆」。已有记录的用户可在「设置 → 记忆」中打开同一入口，摘要有内容时入口位于「更多操作」。应用先在本机统计符合规则的轮次，并显示本批最多调用次数。选 10、25 或 50 轮后点击「开始生成」才会开始调用。历史索引和自动整理开关可独立使用。

历史生成和新聊天共用模型、提取提示词、校验、存储与后续召回。每个请求使用一轮用户文字和相关已保存条目。优先选最近且未处理的轮次，同批按原消息时间从早到晚处理。排除不参与记忆的对话、已知不再提起的来源、拒答或未完成的轮次、常见密钥格式与旧的忘记指令。手动编辑的记忆和时间更新的条目优先。

每个已处理轮次会保存进度。停止后可通过「检查剩余」或重新打开入口继续。条目可在摘要和条目页查看，来源可打开原对话。调用次数上限只涵盖本批，实际费用按 DeepSeek 的输入与输出用量结算。

每轮注入有上限：保存条目正文合计最多约 3200 字符；历史最多 5 段，每段最多 650 字符。存储与上下文预算不同，超出单轮预算的记忆按相关性和更新时间选择，不会全部发送。历史检索是本机全文检索，不是 OpenAI 的语义检索系统，仍可能漏掉同义表达或相关片段。

## 删除和更正

手动编辑后的条目标为手动，自动整理不能覆盖它。较新的自动偏好可替换同主题的旧条目，当前用户纠正优先于历史信息。删除/编辑/清空、关闭开关或排除对话时，尚未完成的旧任务不能将已删除的事实重新写回来。

保存的记忆与原对话独立。删除原对话会移除其历史索引，但不会连带删除已保存的记忆；忘记条目也不删除原对话。如果希望某个信息不再通过历史被引用，需要删除对应原对话或关闭历史引用。旧回答里已经出现的文字不会被自动改写。

本版「单对话不参与记忆」仍会保存聊天记录，不等于 ChatGPT 的不留历史临时聊天；没有加入云同步、跨设备同步或不留历史会话。

## 验证

- `npm test`：中文检索、来源去重、手动条目保护、删除指令约束、密钥过滤、JSON 解析等纯逻辑测试。
- `ANDROID_APP_ID=app.ohmydeepseek.android.importtest node scripts/memory-smoke.mjs`：只允许独立调试包，覆盖跨会话注入、自动提取、偏好替换、来源、忘记、开关、对话排除、并发清空、备份去重和重启。模型响应为本地 fixture，不证明实际模型输出质量。
- `node scripts/live-memory-check.mjs --synthetic-paid-test`：明确 opt-in 的收费验证，仅向实际官方 API 发送人工资料，最多两个请求，不读私有聊天、不修改实际记忆库，也不输出或导出 API Key。已验证提取和后续召回，成功请求合计 504 token。诊断时发现的 400 参数不兼容已修复。

原始运行记录在本机被 Git 忽略的 `evidence/local/`，真实用户档案、凭据和记忆不进入公开仓库。
